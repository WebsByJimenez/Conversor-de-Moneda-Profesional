# 🔀 Mass & Currency Convert — Conversor Multiuso Profesionales

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?logo=github)](https://WebsByJimenez.github.io/Conversor-de-Peso-Profesional/)

Una aplicación web moderna, rápida e intuitiva diseñada para realizar conversiones en tiempo real con precisión. Permite calcular equivalencias tanto de **unidades de peso** (Kilogramos a Libras y viceversa). Construida desde cero usando tecnologías web nativas, cuenta con una interfaz de estética **Neumórfica** y soporte para accesibilidad.

## ✨ Características Principales

- ⚖️ **Conversión de Peso:** Conversión bidireccional instantánea entre Kilogramos (**kg**) y Libras (**lbs**).
- 💱 **Conversión de Divisas:** Cálculo de equivalencias entre distintas monedas en tiempo real.
- 🎨 **Interfaz Neumórfica Modernizada:** Diseño visual táctil y limpio basado en sombras suaves y paleta de colores personalizada.
- 📋 **Copiado al Portapapeles:** Botón integrado con respuesta visual instantánea para copiar los resultados.
- ⌨️ **Atajos de Teclado:** Presiona `Escape` para resetear los valores y volver al campo de entrada al instante.
- ♿ **Código Válido y Accesible:** Estructura que cumple con los estándares oficiales de la **W3C** e incluye etiquetas accesibles para lectores de pantalla.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica completa.
- **CSS3:** Custom Properties (Variables CSS), Flexbox, transiciones suaves y arquitectura Neumórfica.
- **JavaScript (ES6+):** Lógica modular, manipulación del DOM y API de Clipboard (`navigator.clipboard`).
